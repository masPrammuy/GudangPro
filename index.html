Hubungkan Google Cloud OAuth 2.0

Aktifkan login langsung menggunakan akun Google Anda

1
Buka Google Cloud Console

Masuk ke halaman kredensial Google Cloud melalui tautan berikut:

console.cloud.google.com/apis/credentials
2
Buat OAuth Client ID

Klik tombol + CREATE CREDENTIALS di bagian atas > pilih OAuth client ID > pilih Application type: Web application.

3
Tambahkan Authorized JavaScript origins

Di bagian Authorized JavaScript origins, tambahkan URL lokal berikut:

http://localhost:8000
4
Salin Client ID Anda & Tempel di Bawah Ini:
